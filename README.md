# Как писать по-немецки без ошибок

Лендинг Stellas Deutsch: 10 правил немецкой орфографии и пунктуации,
интерактивный диктант на 8 вопросов и тренажёр «живая запятая».

**Живая версия:** https://stellasdeutsch-dev.github.io/ohne-fehler/

## Что внутри

- Mobile-first, один файл `index.html`, без зависимостей и внешних запросов
- Canvas-атмосфера: перья и световые пятна, пауза при скрытой вкладке
- Split-text анимация заголовка, парящий экран платформы с крыльями
- Карусель реальных экранов (3 видео + 8 скриншотов), видео играют только в зоне видимости
- Тренажёр «живая запятая»: 6 союзов, анимированная постановка знака
- Диктант с разбором ошибок и анимированным кольцом результата
- SVG-маршрут A0 → C1, отрисовывается по скроллу
- Реальные отзывы и сертификат Deutsch-Test für Zuwanderer
- Полная поддержка `prefers-reduced-motion`

## Локальный запуск

```bash
python3 -m http.server 4899
```

Затем открыть http://localhost:4899
